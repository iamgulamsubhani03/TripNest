# ✈️ TripNest – Travel Website

TripNest is a travel website project designed to
help users explore beautiful destinations and
discover exciting travel experiences.

The project is being developed using HTML5 and
CSS3 with a focus on modern web design, clean
layouts, and responsive user interfaces.

## 🌍 Features

- Attractive homepage with a hero section
- Navigation bar with multiple sections
- Explore Now button
- Beautiful travel destination cards
- About Us section
- Travel packages section
- Contact section
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
